# Synthetic data
Run the pipeline to generate transactions.csv and transactions.sqlite3. The default is 100,000 fictional payment attempts with seed 42. No personal, employer, payment credentials or real customer data is used. Generated data is ignored by Git.

Fields include a fictional unique transaction ID, timestamp, fictional provider, deposit/withdrawal direction, payment method, KES amount, recent transaction counts, account age, transaction status, latency, expected and actual settlement, and a simulated binary fraud label. Labels are generated by a probabilistic rule and are not evidence of actual fraud.
