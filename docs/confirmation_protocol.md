# Sentinel V4 confirmation protocol

The V3 results motivate a new primary comparison: XGBoost versus logistic regression. Freeze model settings, seeds 2001–2020 (20 fresh datasets of 100,000 attempts), and the primary outcome before execution. Each seed uses the final chronological decile for test, preceding decile for validation, preceding decile for calibration and first seven deciles for fit. Entire timestamp groups stay intact.

Primary contrast: paired XGBoost minus logistic regression hypothetical cost per 1,000 on the original synthetic mechanism. Approximate 95% t interval across 20 paired seed results. Negative favors XGBoost; positive favors logistic regression. An interval crossing zero is inconclusive for superiority. A 95% interval entirely within +/- KES 250 per 1,000 is descriptive evidence of practical similarity under this illustrative, analyst-chosen margin, not a stakeholder-approved equivalence threshold. No model promotion solely on test performance.

Keep review cost KES 25, missed-positive cost KES 1,000 and validation alert capacity 5%. Fit and calibrate each model on disjoint past partitions; optimize thresholds on validation only. For a matched stress comparison, relabel the same final test features using the previously specified alternate mechanism. Same model predictions and thresholds apply to both conditions; no retraining on stress labels. Report stress separately as secondary.

Calibration diagnostics: Brier score before/after calibration, pooled reliability plot using fixed probability bins (descriptive only). Attribution: TreeSHAP raw log-odds for XGBoost and independent-background linear SHAP-equivalent raw log-odds for standardized logistic regression; fixed 256 held-out examples per seed. Report mean and across-seed standard deviation of absolute attributions; correlated engineered features may divide importance, so do not infer causal effects. Drift diagnostics: PSI with validation quantile bins and 0.5 smoothing, comparing validation and test features/scores. A label-only shift cannot be detected from identical features; PSI is not a concept drift detector. No monitoring service is deployed.

All findings remain simulation evidence. External validation requires appropriate real labels, lawful data access, provenance and cost estimates. No observed savings or production readiness are claimed.
